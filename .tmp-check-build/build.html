    Build

    Pick a result. Build it end to end.

    Each guide starts in an empty folder and ends with something running. Every card tells you how long it takes and exactly what you will have. For how things work underneath, the docs go deeper.

    A build guide is one end-to-end path to a working result, not a feature tour. It lists the time it takes, the skill level and the exact package versions it was written against, so you can tell whether it still matches your setup. Commands and code are in order and every step ends in something you can check. Choose by outcome first: read the "You end up with" list on a card and pick the guide whose result you need. Then use the time and level to decide whether to start now. If a term is unfamiliar, the Get started tutorial covers the basics.
