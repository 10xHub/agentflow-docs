    How to reach the maintainers

    • Bugs and feature requests

      Open an issue on the core repository with a minimal reproduction.

      Open an issue

    • Security vulnerabilities

      Do not open a public issue. Use a private GitHub Security Advisory or email contact@10xscale.ai.

      Security policy

    • Contributing code or docs

      Changes pass formatting, lint, type checks, a security scan and an 80 percent coverage gate. One logical change per pull request.

      How to contribute

    • Everything else

      Partnerships, production questions and anything that is not a bug.

      contact@10xscale.ai

    How the project is run

    The repository does not publish a governance document, voting rules or a formal release process, so this page does not describe one. What is written down: releases are announced in the changelog, changes follow thesecurity and contributing policies, and theroadmap says what is planned and what is out of scope. Contributions are accepted under theMIT license. More in About the project.
