10xGraph is maintained by Shudipto Trafder and 10xScale, the company that builds it and runs it in production for its own AI products. It is an MIT-licensed open-source project with a lead maintainer and open contributions. This page lists who maintains it, how to contact them and where to send what.

## Lead maintainer

## How to reach the maintainers

- **Bugs and feature requests:** open an issue on the [core repository](https://github.com/10xHub/agentflow/issues) with a minimal reproduction. [Support](/docs/project/support) explains what to include.
- **Security vulnerabilities:** do not open a public issue. Use a private GitHub Security Advisory or email contact@10xscale.ai, as described in [Security](/docs/project/security).
- **General contact:** contact@10xscale.ai.
- **Contributing code or docs:** read [Contributing](/docs/project/contributing). The core repository's contributing guide lists the checks a change must pass (formatting and lint, type checks, security scan and an 80 percent coverage gate) and asks for one logical change per pull request.

## How the project is run

The repository does not publish a governance document, voting rules or a formal release process, so this page does not describe one. What is documented: releases are announced in the [Changelog](/changelog), the project follows the policies in [Security](/docs/project/security) and [Contributing](/docs/project/contributing), and the [Roadmap](/docs/project/roadmap) states what is planned and what is out of scope. Behavior that is not written down in those pages should not be assumed.
